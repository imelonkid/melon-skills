SKILL · MACOS-DESKTOP-LAUNCH

macOS 桌面上线

首次接入时准备签名材料、下载权限和门户登记。日常发版从门户选版本开始，用用户最终下载的 DMG 验收。

首次接入

  1. 确认发布目标

    核对仓库、桌面端工作流、版本标签前缀、安装包目录和清单地址，建立 GitHub production 环境。

  2. 配置权限与签名材料

    云管理员按 阿里云 OSS 工具（aliyun-oss-tools） 配置项目目录的写入和下载权限。凭据持有人准备 Developer ID 证书、公证密钥，填入对应项目的生产环境。

  3. 验证后登记

    以门户身份读取目标工作流；调用 aliyun-oss-tools 校验脚本向目标目录写入测试文件并匿名读回比对本次内容。维护者合并接入 PR 后，同步门户登记。

发版与验收

发布人选择桌面端和目标版本，流水线通过门禁后打标签，从标签构建、签名并公证。验收脚本核对本次运行、线上版本清单、DMG 摘要、Gatekeeper 和 App 版本。

若分发失败且原构建产物仍可用，可在修复原因后重跑同一版本的失败任务。
