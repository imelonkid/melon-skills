项目初始化

新项目从第一天起就满足运维规范：代码在 GitHub、密钥不进 git、容器有资源上限和健康检查、上线前知道还差什么。将来上线时不用返工。

触发：新建项目 / 初始化工程 / 把已有项目纳入规范
目录 硬性要求流程生成的文件容器规范检查脚本交给用户的事不会做的事

硬性要求

  1. 所有项目必须由 git 托管，远端必须是 GitHub。不用跑在业务服务器上的自建托管（比如 Gitea）：服务器挂了，代码和数据会一起没。
  2. 第一次提交前 .gitignore 就要就位。.env、data/、数据库文件、私钥一律不进 git。
  3. 新仓库默认私有，用户明确说公开才公开。
  4. 默认分支 main；提交信息 <类型>(<范围>): <中文描述>。

流程

  1. 先问清楚

    只问推不出来的，一次问完：项目名、类型（服务 / 静态站 / 库）、技术栈、仓库可见性；服务再问主站点、数据等级、对外域名。

  2. 建目录与 git

    默认 ~/Workspace/<名>。已有项目保留历史只补缺的；发现已提交的密钥就停下来告诉用户。

  3. 生成骨架

    README、CLAUDE.md；服务另加 Dockerfile、compose、.env.example、部署脚本、/health 接口。

  4. 首次提交并推到 GitHub

    提交前逐个确认文件里没有密钥和数据；gh repo create --private --push。

  5. 服务注册

    在私有运维仓库 $OPS_REPO/registry/services/ 登记，状态 building；做不到的条款写进 known_gaps。推不推送问用户。

  6. 检查

    跑 scripts/check.sh，✗ 必须修，△ 写进 README 的「上线前待办」。

  7. 交付

    报告仓库地址、检查结果，以及需要用户本人做的事。

部署脚本做什么

  1. 工作区必须干净

    版本号取 git describe，线上版本能追溯到 commit。

  2. 本机构建 linux/amd64

    服务器上不构建（访问官方源慢）。

  3. 传镜像、同步 compose

    docker save | ssh docker load；compose 文件从仓库同步，服务器上不手改。

  4. 重建并检查健康

    60 秒内 /health 不通就自动回滚到上一版。T0 服务可在 pre-deploy.sh 里先做备份。

容器规范

要求为什么
mem_limit · healthcheck · restart: unless-stopped一个服务吃满内存不能拖垮整台机器；挂了能被发现、能自己起来
端口只绑 127.0.0.1对外统一走反向代理 + HTTPS，不开新的安全组端口
数据只在 ./data/备份只需要盯一个目录
用服务内的 env_file: .env--env-file 插值不会记进容器标签，灾备重建时容易漏
对象存储用 S3 兼容接口主云出事时能切到另一朵云的副本
日志 JSON 到 stdout，敏感字段脱敏统一采集，不泄露密码、token、手机号
SQLite 备份只用 sqlite3 .backupWAL 模式下直接 cp 会拿到不一致的文件

检查脚本

~/.claude/skills/project-init/scripts/check.sh <项目目录>

只读，有 ✗ 时退出码为 1。检查内容：

类别检查项
git是仓库、分支 main、远端在 GitHub、已推送、没有跟踪密钥或数据文件、.gitignore 覆盖 .env 和 data/
文件README、CLAUDE.md；服务另查 .env.example、部署脚本
compose每个服务都有 mem_limit / healthcheck / restart；端口只绑本机；env_file；数据挂载；是否用了厂商专有存储 SDK
注册$OPS_REPO/registry/services/<名>.yaml 是否存在

交给用户的事

  • 在 1Password 创建 ops/<名>/prod，填真实配置；
  • 服务器上建 /opt/<名>/data（需要 sudo 的主机由用户执行）；
  • 对外域名：确认承接站点已完成 ICP 接入、DNS TTL ≤ 300、反向代理与证书；
  • 上线前的准入项（首次备份与恢复验证、探活、告警）在上线时用 server-ops 做。

不会做的事

初始化阶段不 ssh 服务器、不改安全组和 DNS；不替用户在 1Password 或云控制台录入任何东西；不 push --force、不改已有项目的历史；用户没说公开就不建公开仓库。
