安装

运维电脑用 melon-ops/workstation/setup.sh 初始化时会自动克隆并安装本仓库，通常不用单独做。

  1. 克隆

    git clone git@github.com:imelonkid/melon-skills.git ~/Workspace/melon-skills

  2. 安装

    ~/Workspace/melon-skills/install.sh

    把 skills/* 逐个软链到 ~/.claude/skills/，并启用提交前的敏感信息扫描。可以重复执行；同名的已有目录先挪到 ~/.claude/skills-backup/。

  3. 确认环境变量

    zsh -ic 'echo $OPS_REPO $SKILLS_REPO $OPS_SITES'

    为空说明还没装私有仓库的 ops.zsh，先按 melon-ops 的 workstation/README.md 初始化。

ℹ️

本机是软链接。改 ~/.claude/skills/<名> 就是改本仓库，改完记得提交推送。

敏感信息防线

三道防线，越往后越晚、代价越大。

  1. 写的时候：只写变量名

    路径、主机、端口一律用 $VAR 引用；示例值用 __占位符__。

  2. 提交的时候：pre-commit 自动扫描

    scripts/scan-secrets.sh 查公网 IP、私钥、云厂商 AK、各类 token、手机号、身份证号；还会把本机 ops.zsh 里 IP、端口、面板入口的实际值当字面量去搜。命中就拒绝提交。

  3. 随时：全量扫描

    scripts/scan-secrets.sh

    扫全部已跟踪文件。确属误报的行，行尾加 scan:allow。

⛔

已经推上去了怎么办？公开仓库的历史可能已被抓取。先轮换泄露的密钥或改掉暴露的端口，再处理历史——顺序不能反。
